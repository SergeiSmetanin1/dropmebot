## DropMe Portable 1.2.0

Скачай **DropMePortable.zip**, распакуй весь архив и запусти **DropMe.exe**.

### Новое в 1.2.0

- Удаление чата через корзину в списке чатов или в шапке переписки.
- Подтверждение удаления локальной истории из общего профиля DropMe на всех его устройствах. Группа и сообщения в Telegram сохраняются.
- После нового сообщения в Telegram чат появляется снова с новой историей. Старые правки сообщений не восстанавливают удалённую переписку.
- Корректное переключение на другой чат, очистка поля ввода и вложений, обновление списка на подключённых устройствах.

### Возможности из 1.1.0

- «Настройки бота»: заменить, удалить и заново добавить токен после первого входа.
- Подтверждение изменений паролем профиля; новый токен проверяется перед сохранением.
- Сохранение истории при отключении и отдельная переписка для другого бота.
- Управление токеном только на главном компьютере; сетевые сеансы после изменения закрываются.

При обновлении закрой DropMe, сохрани резервную копию своего профиля, распакуй новую программу в отдельную папку и перенеси туда **DropMe.profile**. Пароль и настройки сохранятся.

- Windows 10/11 x64, без установки Node.js и FFmpeg.
- Сообщения, фото, файлы, голосовые и стикеры через своего Telegram-бота.
- Защищённый паролем переносимый профиль и экспорт персонального ZIP.
- Включаемый доступ через браузер из общей локальной сети.

Публичный ZIP не содержит токена, профиля и переписки. При первом запуске создай пароль и введи токен в локальной форме. Персональный ZIP с профилем не загружай в публичный репозиторий.

Сетевой режим использует HTTP и рассчитан на доверенную сеть. На главном компьютере DropMe должен оставаться запущенным. Сборка не подписана; соблюдай ограничения компьютера на запуск приложений.

SHA-256 архива опубликована отдельным файлом. Лицензии компонентов и подробная инструкция находятся внутри архива.
