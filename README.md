# DropMe Portable

Личный чат с Telegram на Windows: сообщения, фотографии, файлы, голосовые и стикеры — без входа в Telegram на компьютере.

## Скачать программу

**[Скачать DropMePortable.zip](https://github.com/SergeiSmetanin1/dropmebot/releases/latest/download/DropMePortable.zip)**

[Все выпуски](https://github.com/SergeiSmetanin1/dropmebot/releases) · [Состояние публикации](https://github.com/SergeiSmetanin1/dropmebot/actions)

Нужна Windows 10/11 x64 и интернет с доступом к Telegram. Устанавливать Node.js и FFmpeg не требуется: они включены в архив. Сборка не подписана; на компьютерах с запретом неизвестных приложений запуск может быть ограничен.

## Первый запуск

1. Скачай **DropMePortable.zip** из Releases и распакуй весь архив в обычную папку.
2. Запусти **DropMe.exe**. Откроется окно программы и вкладка браузера.
3. Создай пароль профиля длиной от 10 символов. Вставь действующий токен своего Telegram-бота в локальную форму. Если прежний DropMe есть на рабочем столе, можно импортировать настройки.
4. Добавь бота в свою Telegram-группу и отправь в ней `/start@DropMeLibrary_bot`. Если используешь другого бота, подставь его имя. Боту нужен доступ к сообщениям группы.
5. Для завершения работы закрой окно **DropMe** и вкладку браузера.

Входить в личный Telegram на компьютере не нужно. Токен в этот репозиторий не загружай.

## Возможности

- Отправка и получение текста, фото и файлов в обе стороны.
- Предпросмотр фотографий и открытие на весь экран.
- Запись голосовых на главном компьютере и воспроизведение входящих.
- Стикеры и добавление наборов Telegram.
- Отметки, выбор сообщений, скрытие и доступные в Telegram редактирование/удаление.
- Светлая и тёмная тема, настройка анимаций.
- Локальный браузерный чат и включаемый доступ из общей сети.

## Доступ из локальной сети

1. Разблокируй профиль на компьютере с DropMe.
2. Включи в окне программы **«Доступ через браузер в локальной сети»**.
3. Открой показанный адрес на другом устройстве в той же сети и введи пароль профиля.

Главный компьютер должен быть включён, окно DropMe — открыто. Телефон только с мобильным интернетом не откроет этот локальный адрес. Рабочая сеть может запрещать соединение устройств между собой. Настройки брандмауэра программа сама не меняет.

Сетевой режим использует **HTTP без TLS**: пароль и сообщения передаются по сети без шифрования. Используй только доверенную локальную сеть. Браузер может блокировать запись микрофона по сетевому HTTP; голосовые можно записывать в Telegram или на главном компьютере.

## Перенос на другой компьютер

В окне DropMe нажми **«Создать архив для переноса…»**. Программа заблокирует профиль и сохранит ZIP с программой, токеном и историей, защищёнными паролем. Храни этот персональный архив у себя. На другом компьютере распакуй его, запусти DropMe.exe и введи пароль.

Персональный архив и файл **DropMe.profile** не публикуй в этом репозитории или его Releases. Публичные выпуски содержат только программу, без профиля и переписки. Забытый пароль восстановить нельзя. Перед удалением папки сохрани актуальный архив для переноса.

Пароль шифрует профиль при хранении (AES-256-GCM, scrypt). После разблокировки токен используется в памяти. Это не защита от администратора или вредоносной программы чужого компьютера. Программа не гарантирует удаление всех следов из Windows и браузера.

## Заменить или удалить токен

На главном компьютере открой **«Настройки бота»** в боковой панели или через значок настроек в шапке чата. Введи пароль профиля и новый токен, затем нажми **«Сохранить новый токен»**. Программа проверит подключение к Telegram перед сохранением. Если проверка не пройдёт, прежний токен останется.

Кнопка **«Удалить токен»** отключает бота и удаляет токен из активного профиля; история остаётся. Добавить токен снова можно в этих же настройках. Отозвать токен во всех приложениях можно через BotFather; ранее сохранённые персональные архивы программа не изменяет.

При замене токена того же бота история сохраняется. Другой бот получает отдельную переписку; прежняя хранится в зашифрованном профиле и возвращается при повторном подключении прежнего бота. После изменения сетевые сеансы закрываются; пользователям нужно войти заново. Подключённым по сети пользователям настройки токена недоступны.

## Удалить чат

Нажми **корзину рядом с чатом** в списке или в шапке открытой переписки и подтверди удаление. Чат и его локальная история удалятся из общего профиля DropMe на всех подключённых устройствах. Группа и сообщения в Telegram сохраняются.

После нового сообщения в Telegram чат появится снова с новой историей. Редактирование старого сообщения не восстанавливает удалённую переписку. Персональные ZIP-архивы, сохранённые до удаления, программа не изменяет.

## Если Telegram не подключается

- Запускай **DropMe.exe** и используй вкладку, которую открыло приложение.
- Проверь действующий токен в своём профиле. Токен после перевыпуска в BotFather меняется.
- Оставляй запущенной одну копию программы с одним ботом, чтобы избежать конфликта получения обновлений.
- Посмотри текст ошибки подключения в чате. Доступность Telegram в браузере не гарантирует доступность `api.telegram.org` из программы.

Бот получает историю с момента получения обновлений; Telegram Bot API не загружает всю старую историю группы. Редактируются сообщения, отправленные ботом. Удаление чужих сообщений в группе требует соответствующих прав.

## Содержимое репозитория

Здесь находятся инструкция, скомпилированные компоненты и сценарий публикации Windows-архива через GitHub Actions. Исходники приложения отдельными файлами не публикуются. Технический анализ исполняемых файлов и браузерного интерфейса полностью исключить невозможно.
